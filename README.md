# Aniruddha QA Lab — Editable VS Code / Antigravity Project

A standalone static portfolio, extracted from the latest editable QA Lab source. No build tools or dependencies are needed to view or deploy it.

## Open locally

1. Extract this ZIP and open **the folder** in VS Code or Antigravity IDE.
2. On Windows, double-click `run_portfolio.bat`; alternatively open `index.html` in your browser.
3. To preview with an IDE extension, use Live Server (optional). No npm install is required.

## Edit your portfolio

- **Name, role, intro, contact, skills, achievements, experience, projects, case studies:** `content/data.js`.
- **Website layout, sections and text not driven by data:** `index.html`.
- **Colors, spacing, animation and mobile styling:** `assets/css/styles.css`.
- **QA characters and conversations:** `assets/js/qa-crew.js`.
- **Interactive demo test flow:** `assets/js/test-runner.js`.
- **Case study interaction:** `assets/js/case-studies.js`.
- **Resume:** replace `Aniruddha_Lokare_Resume.pdf` (or update `profile.resume` in `content/data.js`).

**Tip:** Make a backup or commit changes to Git before large edits. The `profile.github` value is currently `#`; add your real GitHub URL to show the GitHub link.

## Deploy to Vercel

Upload/import the project folder as a **static site**, with no framework preset, build command or output directory. The root `index.html` is the entry point. `run_portfolio.bat` is Windows-only and not used online.

## Accuracy

The clickable portfolio tests, bug lifecycle and test outputs are *demonstrations/simulations*, not live tests of an actual production backend. Keep this distinction when presenting to recruiters.

## Migration notes

This is a **structural refactor**, not a visual redesign. The original CSS rules were moved in the same order and existing JavaScript execution positions were retained. `content/data.js` is loaded before the scripts that use it, fixing a prior load-order risk. No QA characters or features were intentionally removed.


## Real Playwright + TypeScript test suite

The portfolio itself is still a standalone HTML/CSS/JS site. npm is **only** needed to run real browser tests. The interactive website test runner remains a clearly labeled simulation.

In VS Code or Antigravity, open a terminal in this project and run:

```bash
npm install
npx playwright install chromium
npm test
npm run test:report
```

Additional commands: `npm run test:headed`, `npm run test:ui`, `npm run test:chromium`, `npm run test:mobile`. The test framework starts its own local web server on port 4173. The original `run_portfolio.bat` still works without npm.

Tests cover profile/data, navigation, case-study interactions, recruiter links, PDF, crew count, simulation trigger, mobile menu, and viewport overflow. Reports/screenshots/traces are generated by Playwright; they are real automated browser checks, separate from the illustrative portfolio simulation.

GitHub Actions workflow: `.github/workflows/playwright.yml`.
