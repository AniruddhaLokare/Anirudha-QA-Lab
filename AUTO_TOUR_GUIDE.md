# Guided Auto Tour — Recording Mode

Open your deployed portfolio with `?tour=1` appended to the URL, for example:
https://anirudhaqalabportfolio.vercel.app/?tour=1

Or open `index.html?tour=1` locally.

1. Start screen recording (Snipping Tool, OBS, or Clipchamp).
2. Click **Start Tour**. The page navigates section by section with pauses.
3. Space pauses/resumes. Left/right arrows navigate. H hides/shows the control bar. Esc exits.
4. Choose Fast/Normal/Slow to adjust how long each section stays visible.
5. Edit the resulting recording and export an MP4.

The regular website URL remains unchanged. The 09 / PORTFOLIO UNDER TEST section is preserved inside a non-rendering HTML template. The tour does not run tests or automatically click buttons; pause it to demonstrate interactions manually.
